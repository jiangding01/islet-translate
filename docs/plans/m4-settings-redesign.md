# M4 设置页重做：按 Design 原型统一「翻译风格」「术语库」

> 状态：2026-11-26 用户确认原型与新文案，开始实现。起因是用户真机验收时发现两点：
> - 术语库用的是行内表单，而「添加风格」「添加服务」用的是对话框，交互不一致；
> - 两个新页面都没有先在 Design 里出原型，违反 `docs/plans/ui-isle-direction.md` 第 121 行「每个批次的 UI 都要先出高保真原型」。
>
> 「取消要点两次」的修复已经在 #96 里（失焦不再显示必填提示）。本 PR 基于 #96 的分支开发。

- 复用的现有部件：「设置页与面板 · 琥珀」页的 `Settings.dc.html`，以及代码里已有的样式类与组件：
  - 页头和「已保存」提示；

## 改什么
### 翻译风格页（`StylesPage.tsx`、`StyleDialog.tsx`）
1. 分区标题行：标题「风格」，说明「只对 AI 引擎生效，Google 翻译不受影响」**常驻**，取代原来只在默认引擎是 Google 时才出现的 `googleNote`；右侧是「添加风格」按钮。
2. 卡片网格三列：
   - 每张卡片左侧加单选圆点；
   - 「通用」卡片带「默认」标签，复用 `options.general.defaultBadge`；
   - 选中的卡片用琥珀描边和浅底；
   - 自定义卡片右上角放「编辑」「删除」两个图标按钮；
   - 删除确认在卡片内部展开，提示复用现有文案。
3. 对话框：在说明框下方固定一行，左侧放错误提示，右侧放字数统计，提示出现时按钮不会移动。名称为空的提示只在「输入过又清空」时出现（#96 已实现）。

### 术语库页（`GlossaryPage.tsx`，可拆出 `GlossaryDialog.tsx`）
1. 分区标题行：标题「术语」，有词条时旁边显示「n / 500」，空库时不显示；右侧是「添加术语」按钮。
2. 添加和编辑改用**对话框**，写法与 `StyleDialog` 一致：
   - 标题为「添加术语」或「编辑术语」；
   - 字段依次是：原文、译文（占位「留空则保持原样」）、目标语言（只在填了译文时出现，用 `Select`）、「区分大小写」复选框；
   - 原文为空的提示只在「输入过又清空」时出现；
   - 「已有相同原文的术语」由后台判重，点「保存」后才提示，对话框保持打开。
3. 列表沿用引擎列表的卡片行，五列定宽：原文、箭头、译文、语言（96px，右对齐）、操作（60px）。各行的原文、箭头、译文因此上下对齐。
   - 译文为空的显示「保持原样」标签；
   - 区分大小写的词条显示 `Aa`，旁边配读屏文字「区分大小写」；
   - 编辑、删除按钮始终可见；
   - 删除确认在该行下方就地展开，使用现有文案。
4. 新词条追加在末尾（显示顺序即存储顺序），并闪一下。
5. 空态：在卡片里居中放一个图标和现有空态文字，只保留标题行那一个「添加术语」按钮。
6. 焦点：对话框关闭后，焦点回到打开它的按钮，原按钮已消失或被禁用时回到分区；删除后焦点回到「添加术语」，规则与 #95 相同。

## 实施记录
- **术语列表改用共享 grid（偏离「96px / 60px 定宽」）**：列表容器 `grid-template-columns: minmax(0,1fr) 16px minmax(0,1fr) auto auto`，每行（含就地删除确认）`grid-column: 1 / -1` + `grid-template-columns: subgrid`。原因：用户补充要求兼顾长内容，定宽列在语言名或标签变长时会溢出或被截，共享 grid 让所有行共用同一组列宽，内容再长也对齐。subgrid 从 Chrome 117 起支持，manifest 的 `minimum_chrome_version` 是 130。
- **长内容**：原文、译文最多显示 2 行（line-clamp）并 `overflow-wrap: anywhere`，全文留在 DOM；各列顶部对齐，箭头对齐第一行。语言标签、「保持原样」单行省略。自定义风格名称单行省略并给右上角按钮留位；自定义风格说明最多 3 行。内置风格说明不截断：英文界面较长，截断会丢信息。
- **对话框标签列**：两个对话框的字段放进同一个 grid，标签列 `minmax(76px, max-content)`，各行用 subgrid，英文、繁体的长标签不溢出，复选框与输入框同列。
- **文案占位符**：`options.glossary.count` 写成 `$1 / $2`（上限取常量 `MAX_GLOSSARY_ENTRIES`），`options.styles.sectionHint` 的 Google 名称用 `$1`（取 `engine.googleName`），显示结果与方案表格一致。
- **焦点**：风格页同样按术语库的规则归还焦点（对话框关闭回到打开它的按钮，按钮消失或禁用时回到分区；删除后回到「添加风格」；取消删除回到该删除按钮）。
- **闪动**：新增和编辑后的词条都闪一下（与原型一致）。
- **暗色**：术语行的语言、`Aa` 标签底色改用文字色 6% 的混色；原型用 surface 色，暗色下与卡片几乎同色，看不出标签。
- **体积**：options 94.68 → 95.30 KB（预算 150）；content 7.67、background 65.14、popup 83.53 与改动前一致（同机构建 HEAD 对比）。
