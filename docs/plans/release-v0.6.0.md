# 发版 v0.6.0 方案

> 状态：发版 PR #89；`v0.6.0` 标签在 PR 合并、main CI 全绿后经用户确认再推送（第 2 步）。依据：发版节奏（主题批次收尾后发 0.x）；体验债小批的必做项（AI 逐段显示与撤回重译）完成，并已真机验收，2026-11-25 用户说「开始发版」。做法沿用 `docs/plans/release-v0.5.0.md`，发版工作流 `.github/workflows/release.yml` 本次不改。

## 现状（2026-11-25，main `1d3f10c`）
- `package.json` / `package-lock.json` 版本 `0.5.0`；已有 `v0.5.0` 标签与 GitHub Release。
- CHANGELOG `[未发布]` 含：
  - 体验债小批 PR①（#83）：AI 批量翻译逐段显示与增量解析；
  - 体验债小批 PR②（#87）：长度对照拦截与撤回重译；
  - #88：翻译默认关闭 DeepSeek 思考模式，设置里新增「思考模式」开关；
  - 依赖小版本升级 #84–#86（无用户可见变化）。
- 真机验收（2026-11-25，用户）：
  - deepseek-flash 整页翻译逐段出现，没有夹带思考内容；
  - 关闭思考后明显更快，打开后明显更慢。
  - 错位撤回很难人为触发，以单测与集成测试为准。
- 版本号取 **0.6.0**。理由：
  - 新增用户可见行为（逐段显示、撤回重译）和一个设置项（`providers.deepseek.thinking`）；
  - 配置只追加字段，旧配置自动补默认值，不升 `schemaVersion`；
  - 没有破坏性改动，仍保持 0.x。

## 第 1 步：发版 PR（分支 `chore/release-v0.6.0`）
1. **版本号**：`npm version 0.6.0 --no-git-tag-version`。
2. **CHANGELOG**：
   - `[未发布]` 改名为 `[0.6.0] - 2026-11-25`，其上新增空的 `[未发布]`；
   - 最上方加「本版要点」（需用户确认）；
   - 补一节「依赖」，记 #84–#86；
   - 底部比较链接已更新。
3. **README 双语**：
   - 安装示例改为 v0.6.0；
   - 整页翻译一行补上 AI 逐段显示与撤回重译；
   - 引擎表 DeepSeek 一行注明默认关闭思考、可在设置里打开；
   - 路线图把体验债小批必做项与 v0.6.0 标为已完成。
4. **HANDOFF**：写成发版后的终态。
5. **本方案**补实施记录。

## 第 2 步：合并后打标签发版
1. 确认 `main` 上发版 PR 合并提交的 CI 全绿。
2. **经用户确认后**：`git tag -a v0.6.0 -m "v0.6.0"`，`git push origin v0.6.0`。
3. 发版工作流跑完后读回 Release，核对三项：
   - 下载 zip，`manifest.json` 版本为 0.6.0；
   - SHA-256 与校验文件一致；
   - 发布说明即 `[0.6.0]` 一节。
4. 建议用户用下载的 zip 在 Chrome 里加载一次，用 AI 引擎整页翻译一个页面。
